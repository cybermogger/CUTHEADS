# CUTHEADS — свой характер

Независимый концепт для портфолио liquidsss. Не официальный сайт и не заказ Cutheads.

Светлый editorial / brutalism: строгая сетка, узкая рубленая типографика Oswald, лаймовый акцент, монохромные фотографии с проявлением цвета при наведении. Адаптивная страница, аккордеон услуг, фильтры галереи, просмотр фотографий, демонстрация записи с выбором услуги, даты и времени. Ничего не отправляется в барбершоп.

Сайт: https://liquidsss.github.io/CUTHEADS/ . HTML/CSS/JS без сборки. Откройте index.html или используйте статический HTTP-сервер в корне репозитория. GitHub Pages публикует main, папку / (root).

Источник адреса, времени работы, телефона, услуг и цен: https://cutheads21.ru/ . Цены требуют уточнения у барбершопа. Фотографии взяты с этого сайта: каталог /wp-content/uploads/2026/03/, файлы 20251209-van07261-scaled.jpg.webp, 20251209-van06831-scaled.jpg.webp, 20251209-van06822-scaled.jpg.webp, 20251209-van06645-scaled.jpg.webp. Права принадлежат правообладателям. Концепт не подразумевает передачу прав на фотографии или бренд.

Шрифты Golos Text и Oswald через Google Fonts с системными заменами. Пользовательский ввод выводится через textContent.
